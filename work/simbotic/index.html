Simbotic

Simbotic is an open-source simulation engine and AI platform. I led its development as lead simulation and AI engineer from 2018 to 2022. It generates synthetic data for training perception models and runs robots in simulation before real-world tests.

Simbotic on GitHub ↗simbotic.ai ↗
Engine
Unreal Engine 4.24, PhysX 4.0
Media
GStreamer
Learning
PyTorch, LibTorch
Years
2018–2022

Components

  • SimboticEngine: Unreal Engine 4.24 with NVIDIA PhysX 4.0 for simulation and robotics
  • Synthetic: Unreal Engine plugin that generates synthetic training data from simulation
  • Streamer: runs GStreamer pipelines inside Unreal Engine
  • SimboticTorch: a LibTorch plugin for GStreamer, written in Rust
  • DynamicalSystems: Unreal Engine plugin for dynamical systems simulation
  • Simula: a Rust 3D engine for XR and embodied AI
