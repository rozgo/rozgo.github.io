Autonomy harness · Rust · 2026

Veoveo

A self-hosted autonomy harness for physical AI, where humans, robots and agents learn, play and evolve together in simulated and real worlds. Agents rehearse in simulation and command robots in the field through the same controls.

An operator typed “fly to Times Square”, and the pilot agent planned the route and flew it, using only the vehicle it was allowed to command.

RL and game dev harness · C, CUDA, WebAssembly · 2026

AlienWars Gym

A reinforcement learning and game development harness. Coding, design and NPC agents use it as a world model: they explore procedurally generated 3D worlds in simulation and train policies inside the development loop.

A whole fleet retrains in under 20 minutes on one GPU, so agents can test a design change in the same session.

World models · Rust, CUDA · 2026

JEPA world models

A Rust and CUDA runtime for JEPA world models. SkyJEPA, rebuilt from its paper, learns how a drone moves and plans its rotor commands, and the JEPA Gym compares model variants on the same drone in MuJoCo.

The learned model made a hand-written flight controller more accurate, and it passed every tracking run across three training seeds and four test conditions.

Language models · Python · 2026

Doom Sandbox

Language and embedding models playing Doom: a trained ModernBERT classifier that reads the game state as text, GLiNER2.5 zero-shot and then fine-tuned, and EmbeddingGemma 2 reading the screen.

EmbeddingGemma 2 plays from the screen with no training: each decision compares crops of the frame against text prompts.

Formal methods · Lean 4, Three.js · 2026

Maquina

An execution model for simulated worlds. A Lean 4 kernel checks every state change, and each run can be replayed. Agents, people and planners propose actions; the kernel accepts or rejects each one.

Play a mission in the browser and see why every order is accepted or refused, then rewind and try another path.

Decision engine · Rust, WebAssembly · 2026

Axionomy

A Rust engine that models a problem as accounts, assets and exchanges. Search, optimization and reinforcement learning propose exchanges; the engine validates each one and keeps a replayable trace.

The same engine solves a maze, runs a market and schedules a league of agents, and shows the reason behind every decision.

05 · About

Alex Rozgo

I started in console games, writing gameplay, physics and networking code at LucasArts and other studios across the industry. Since 2016 I have worked on simulation for robotics, autonomy and defense, and on the perception and learning systems trained in those simulations.

I prefer small sets of well-defined parts: typed state, explicit rules, and runs that can be replayed. I write Rust by choice, C and CUDA where performance requires it, and Python for training and tooling.
